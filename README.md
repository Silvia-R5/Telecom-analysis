# Telecom-analysis
**Objetivo del proyecto**
Analizar el negocio usando los 3 datasets para que la empresa entienda cómo se comportan sus usuarios según edad, volumen de llamadas/mensajes y nivel de consumo. 

**Datasets utilizados**
plans, users, usage

**Etapas del análisis realizadas**
- Identificar problemas de calidad de datos: Contar nulos, detectar sentinels, revisar fechas fuera de rango.
- Limpieza básica: reemplazar sentinels, convertir fechas, imputar y marcar como NA segun corresponda.
-Medidas clave (media, mediana, percentiles) que muestran el comportamiento típico y extremo.
- Visualización & outliers: Identificar sesgos patrones de usuarios o datos atípicos.
- Segmentación: Aprovechar los segmentos de clientes para desarrollar ofertas y campañas específicas que incrementen el consumo y promuevan la migración a planes de mayor valor.
- Insight ejecutivo: Se redactaron conclusiones y recomendaciones basadas en el analisis de los planes y segmentos.
  
**Cómo ejecutar el notebook** 

**Breve guía de reproducción**
Descargar el repositorio desde GitHub.
Abrir el archivo .ipynb en Jupyter Notebook
Instale las bibliotecas requeridas (pandas, numpy, matplotlib y seaborn, entre otras que utilice el proyecto).
Verifique que el archivo de datos se encuentre en la ruta indicada por el notebook.
Ejecute las celdas en orden, de principio a fin, para reproducir el análisis y los resultados.
